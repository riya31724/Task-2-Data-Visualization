# Data Visualization & Storytelling - Task 2

## Project Title
Amazon Sales Dashboard (Power BI)

## Objective
The objective of this project is to analyze sales data and create meaningful visualizations to derive business insights using Power BI.

## Dataset Used
Amazon Sales Dataset (Excel File)

## Tools Used
- Power BI Desktop

## Visualizations Created
1. Total Sales, Profit & Quantity (KPI Cards)
2. Sales by Category (Bar Chart)
3. Profit by Category (Bar Chart)
4. Monthly Sales Trend (Line Chart)
5. Sales by Geography (Column Chart)
6. Top 10 Products (Bar Chart)

## Key Insights
- Certain products contribute major share of revenue.
- Sales vary across different categories.
- Monthly trend shows peak sales periods.
- Geography impacts overall performance.
- Top 10 products generate significant sales.

## Conclusion
This project helps in understanding business performance through data visualization and improves decision-making using insights derived from sales data.
